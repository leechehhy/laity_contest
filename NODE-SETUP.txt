=========================================================
  제1회 광주대학교 L'AI'TY 경진대회 신청 사이트
  Node.js 준비 안내
=========================================================

이 프로그램을 실행하려면 컴퓨터에 Node.js 가 있어야 합니다.
설치할 패키지는 없습니다. Node.js 하나만 준비하면 됩니다.

아래 두 가지 중 편한 방법 하나만 하시면 됩니다.


---------------------------------------------------------
[ 방법 1 ]  설치하기  - 관리자 권한이 있는 경우
---------------------------------------------------------

 1. 인터넷 주소창에  https://nodejs.org  입력

 2. 큰 초록색 버튼 중 "LTS" 라고 적힌 것을 눌러 내려받기

 3. 내려받은 파일을 실행하고 계속 "다음(Next)" 을 눌러 설치
    (특별히 바꿀 설정 없습니다)

 4. 설치가 끝나면 이 창을 닫고, START.bat 을 다시 더블클릭


---------------------------------------------------------
[ 방법 2 ]  설치 없이 쓰기  - 관리자 권한이 없는 경우
---------------------------------------------------------

 1. 인터넷 주소창에  https://nodejs.org/en/download  입력

 2. 아래 조건으로 선택합니다
      - 운영체제 : Windows
      - 아키텍처 : x64
      - 형식     : ZIP        <-- 중요! Installer 가 아니라 ZIP

    내려받은 파일 이름 예)  node-v22.14.0-win-x64.zip

 3. 내려받은 zip 파일을 마우스 오른쪽 클릭 - "압축 풀기"

 4. 압축을 풀면  node-v22.14.0-win-x64  라는 폴더가 나옵니다.
    이 폴더의 이름을  node  로 바꿉니다.  (숫자 부분 전부 지우기)

 5. 이름을 바꾼  node  폴더를
    START.bat 이 들어 있는 폴더 안으로 통째로 옮깁니다.

    이렇게 되면 성공입니다:

        laity-site
          |- START.bat
          |- server.js
          |- config.json
          |- node                <-- 여기에 옮기기
          |    |- node.exe
          |- public
          |- lib

 6. START.bat 을 다시 더블클릭


---------------------------------------------------------
[ 그래도 안 될 때 ]
---------------------------------------------------------

 * 검은 창이 바로 꺼진다면:
   START.bat 을 마우스 오른쪽 클릭 - "터미널에서 열기" 또는
   폴더 주소창에 cmd 를 입력해 검은 창을 연 뒤
   아래를 입력하고 Enter 를 눌러 보세요.

       node server.js

   화면에 나오는 메시지를 그대로 알려 주시면 확인해 드립니다.

 * "이 페이지에 연결할 수 없습니다" 가 뜬다면:
   검은 창이 아직 떠 있는지 확인하고,
   브라우저에서 F5(새로 고침)를 눌러 보세요.

 * 백신/보안 프로그램이 차단했다는 안내가 뜨면 "허용" 을 눌러 주세요.
