# 제1회 광주대학교 L'AI'TY 경진대회 — 참가신청 사이트

교내에서만 운영하는 소규모 공모전 접수 사이트입니다.
외부 서비스(구글폼 등)를 쓰지 않고, 신청 내용과 첨부파일이 **모두 이 폴더 안에만** 저장됩니다.

---

## 1. 처음 실행하기

이 프로그램은 **외부 라이브러리를 하나도 쓰지 않습니다.** `npm install` 이 필요 없고,
인터넷이 막힌 사내망에서도 그대로 동작합니다. 필요한 것은 **Node.js 하나뿐**입니다.

### ① Node.js 준비 — 둘 중 하나만 하면 됩니다

**방법 1. 설치하기 (관리자 권한이 있는 경우)**

<https://nodejs.org> 접속 → **LTS** 버튼으로 내려받기 → 계속 “다음”을 눌러 설치.

**방법 2. 설치 없이 쓰기 (관리자 권한이 없는 경우)**

1. <https://nodejs.org/en/download> 접속
2. **Windows / x64 / ZIP** 형식을 선택해 내려받기 (예: `node-v22.x.x-win-x64.zip`)
3. 압축을 풀면 `node-v22.x.x-win-x64` 폴더가 나옵니다
4. 그 폴더 이름을 **`node`** 로 바꾸고, `START.bat` 이 있는 폴더 안으로 통째로 옮깁니다

```
laity-site\
  START.bat
  server.js
  node\          ← 이렇게 되면 됩니다
    node.exe
```

`START.bat` 은 폴더 안의 `node` 를 먼저 찾고, 없으면 PC에 설치된 Node 를 씁니다.
자세한 그림 설명은 폴더 안 **`NODE-SETUP.txt`** 에 있습니다.

### ② 사이트 실행

| 운영체제 | 실행 방법 |
|---|---|
| Windows | `START.bat` 더블클릭 |
| macOS / Linux | 터미널에서 `./start-mac.command` |

검은 창이 뜨고 3초 뒤 브라우저가 자동으로 열리면 성공입니다.

> 검은 창은 **끄지 마세요.** 이 창이 켜져 있는 동안만 사이트가 동작합니다.
> 사이트를 중지하려면 검은 창에서 `Ctrl + C` 를 누르거나 창을 닫습니다.

### ③ 주소

| 화면 | 주소 |
|---|---|
| 신청 사이트 | <http://localhost:3000> |
| 관리자 | <http://localhost:3000/admin> |

## 2. 교내 다른 직원들이 접속하게 하기

`localhost` 는 이 컴퓨터에서만 열립니다. 다른 직원이 쓰려면 **이 컴퓨터의 IP 주소**를 알려 주세요.

1. Windows: 검은 창(명령 프롬프트)에서 `ipconfig` 입력 → `IPv4 주소` 확인 (예: `10.1.2.34`)
2. 직원들에게 `http://10.1.2.34:3000` 을 안내
3. 방화벽 알림이 뜨면 **허용**을 눌러 주세요

정식으로 운영하려면 정보전산원에 아래 내용을 요청하시면 됩니다.

- 교내 서버 1대(또는 가상머신)에 Node.js 설치 후 이 폴더를 올려 `node server.js` 실행 (별도 패키지 설치 불필요)
- `laity.gwangju.ac.kr` 같은 내부 도메인을 3000번 포트로 연결
- 24시간 자동 실행이 필요하면 `pm2` 사용 → `npm install -g pm2` 후 `pm2 start server.js --name laity`

## 3. 관리자 사용법

`http://localhost:3000/admin` 접속 → 비밀번호 입력 (초깃값 `laity2026!`)

| 기능 | 설명 |
|---|---|
| **엑셀 다운로드** | 신청 내용 전체를 xlsx로 내려받습니다. `참가신청 목록` 시트와 `질의응답` 시트 두 장으로 구성되며, 헤더 고정·필터가 걸려 있어 바로 정렬·필터해서 쓸 수 있습니다. |
| **첨부파일 전체 ZIP** | 모든 첨부파일을 `접수번호_이름_서비스명` 폴더로 정리해서 한 번에 내려받습니다. 평가위원 배포용으로 그대로 쓰시면 됩니다. |
| 개별 다운로드 | 목록에서 파일명을 클릭하면 그 파일만 받습니다. |
| 검색·필터 | 이름·부서·서비스명 검색, 분야별·보고서 제출 여부별 필터 |
| 질의응답 관리 | 질문에 답변을 쓰고 저장하면 게시판에 바로 반영됩니다. 비밀글 내용도 관리자에게는 보입니다. |

**비밀번호는 꼭 바꿔 주세요.** `config.json` 파일의 `adminPassword` 값을 수정하고 서버를 다시 시작하면 됩니다.

## 4. 문구·일정 수정하기

`config.json` 파일 하나만 메모장으로 열어 고치면 사이트 전체에 반영됩니다. (수정 후 서버 재시작)

| 항목 | 설명 |
|---|---|
| `adminPassword` | 관리자 비밀번호 |
| `contest` | 대회명, 슬로건, 주제, 참가 대상 |
| `schedule` | 접수 기간(D-day 자동 계산), 추진 일정 5단계 |
| `categories` | 응모 분야 (신청 폼의 선택지와 메인 카드가 함께 바뀝니다) |
| `awards` | 시상 내역 |
| `judging` | 평가 단계 안내 (1차 서면평가 → 2차 발표평가) |
| `contact` | 문의처 부서·전화·이메일·운영시간 |
| `faq` | Q&A 페이지의 자주 묻는 질문 (질문/답변 쌍을 추가·삭제) |
| `notice` | 메인 페이지 유의사항 |
| `upload` | 첨부파일 최대 크기(MB), 허용 확장자 |

JSON 파일이라 **쉼표와 따옴표를 지우지 않도록** 주의해 주세요. 저장 후 사이트가 안 열리면 대개 쉼표 문제입니다.

## 5. 자료 보관과 백업

| 폴더 | 내용 |
|---|---|
| `data/` | 신청 내용, 질의응답 (JSON 파일) |
| `uploads/` | 참가자가 올린 첨부파일 원본 |
| `forms/` | 참가자가 내려받는 AI 활용 사례 보고서 양식 |

**백업은 `data` 와 `uploads` 두 폴더만 복사**하면 됩니다. 별도 DB 프로그램을 설치하지 않았기 때문에 폴더를 통째로 USB에 옮겨 두면 그대로 복원됩니다.
접수 기간에는 하루에 한 번 정도 복사해 두시길 권합니다.

## 6. 참가자 화면 구성

```
메인 (/)               대회 소개 · 응모 분야 · 일정 · 평가 · 시상 · 유의사항
  └ 참가 신청 (/apply)  신청 폼 + 보고서(필수)·증빙자료 업로드 → 접수번호 발급
  └ 접수 확인 (/check)  접수번호 + 비밀번호로 조회 → 내용 수정, 파일 추가 업로드
  └ Q&A (/qna)         자주 묻는 질문(펼침) + 질문 게시판(비밀글 가능)
```

- 신청할 때 보고서를 반드시 첨부해야 접수가 완료됩니다. 접수 기간 안에는 **접수 확인** 메뉴에서 다시 올려 교체할 수 있습니다.
- 참가자 비밀번호는 암호화(scrypt 해시)해 저장하므로 관리자도 원문을 볼 수 없습니다. 분실 시에는 관리자가 해당 건을 삭제하고 재신청받아야 합니다.

## 7. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `START.bat` 을 눌러도 창이 바로 꺼짐 | Node.js가 설치되지 않은 경우입니다. 1번 항목부터 다시 진행해 주세요. |
| `Error: listen EADDRINUSE` | 이미 사이트가 켜져 있습니다. 기존 검은 창을 닫고 다시 실행하세요. 또는 `config.json`의 `port`를 3001 등으로 바꾸세요. |
| 다른 PC에서 접속 안 됨 | 방화벽에서 3000번 포트를 허용해야 합니다. 2번 항목 참고. |
| 첨부파일 업로드 실패 | `config.json`의 `maxFileSizeMB`(기본 50MB)를 넘었거나 허용 확장자가 아닙니다. `allowedExt`에 확장자를 추가하세요. |
| 글꼴이 다르게 보임 | 별도 웹폰트 없이 시스템 글꼴을 사용합니다(Windows 맑은 고딕). 인터넷이 되는 환경이면 Pretendard를 설치하면 더 보기 좋습니다. |

## 8. 기술 정보 (정보전산원 참고용)

- Node.js 18 이상. **외부 의존성 0개** — `npm install` 불필요, 폐쇄망에서 그대로 동작
- 웹 서버·라우팅·multipart 업로드: `lib/http.js` (Node `http` 모듈만 사용)
- 엑셀(.xlsx) 생성: `lib/xlsx.js` (OOXML 을 직접 작성)
- ZIP 생성: `lib/zip.js` (deflate + UTF-8 파일명 플래그)
- 저장소: `lib/store.js` — `data/*.json` (임시파일 교체 방식으로 안전하게 기록)
- 첨부파일: 확장자·용량 검증, 저장명은 난수로 변경(경로 조작 방지)
- 비밀번호: `crypto.scrypt` 해시 + 솔트, 원문 미저장
- 관리자 인증: HMAC 서명 토큰을 HttpOnly 쿠키에 저장, 12시간 만료

문의 사항이 있으면 `config.json`의 담당자 연락처를 실제 정보로 바꾼 뒤 배포해 주세요.
